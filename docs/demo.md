# Five-minute judge walkthrough

1. Explain the bridge: quantum education often separates abstract equations from observable outcomes. Qubit Quest connects a prediction, a simulation, and a spatial representation.
2. Complete the first quiz. Show XP and refresh to demonstrate saved local progress.
3. In Quantum lab, reset, apply H, then H. Explain why the final measurement is certain. Apply H then S and explain equal probabilities with changed phase. Run with Qiskit to compare.
4. Run Bell and discuss correlated counts and a mixed individual qubit. Run Grover and explain the phase oracle and diffusion. Run QFT and expand the complex amplitudes.
5. Select QAOA and sweep the cost angle. Select variational energy and compare trial energy with the exact ground energy. State explicitly that this is a toy spin model, not an H2 calculation.
6. Open the immersive lab. Show desktop orbit and gate controls. Only claim a Quest demonstration after testing on the actual headset; use the Unity setup guide for the native path.

The opening brief lists a project notebook and presentation slides as submission items, with GitHub optional. This repository supplies a demo notebook. Team slides, registration, and submission still need team action. Do not assume creating this repository submits the project.

Be ready to explain Born's rule, relative phase, bit ordering, oracle assumptions, QAOA angles, variational bounds, and why simulation is not quantum advantage.
